## 2023-10-21 - Canvas Pixel Reading Overhead
**Learning:** Calling `getImageData` on a `<canvas>` element continuously inside a tight nested loop creates extreme performance overhead. This is because crossing the JS/browser boundary forces pixel data reading for every single operation, destroying performance for high-iteration spatial calculations (like generating raster views for GIS maps).
**Action:** Always fetch the entire `ImageData` block outside the loop with a single `ctx.getImageData(0, 0, width, height)` operation. Calculate the linear offset dynamically using math (`idx = (Math.trunc(y) * width + Math.trunc(x)) * 4`) and access pixel values directly from the stored `Uint8ClampedArray` within loops. Ensure index coordinate calculations are explicitly mapped to integers when deriving indexes from external GIS mapping values.
