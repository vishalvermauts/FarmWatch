## 2025-02-23 - [Critical] SSRF Vulnerability in Google Earth Engine Proxy
**Vulnerability:** Server-Side Request Forgery (SSRF) and credential leakage in the `/api/satellite/tile` endpoint. An attacker could pass a malicious URL in the `mapName` parameter, forcing the server to issue a GET request to an attacker-controlled endpoint. This would leak the Google Earth Engine OAuth access token because it was attached to the outgoing request via the `Authorization: Bearer <token>` header.
**Learning:** Even when abstracting third-party APIs via proxy routes to hide credentials from the client, dynamic URL reconstruction from user inputs must be strictly validated. The proxy mechanism was correctly passing the `Authorization` header to a dynamically generated URL based on `mapName` but failed to restrict the domain to the expected `earthengine.googleapis.com` origin.
**Prevention:** Always validate and whitelist the origin/hostname of user-supplied URLs before appending authorization headers or forwarding requests. Reject any inputs that do not strictly match the required target domain.
